# LearnTrack Application

A console-based Java application for managing students, courses, and enrollments in an educational system. Users can add, view, and manage students and courses, as well as handle enrollments (e.g., enrolling students in courses, viewing enrollments, and updating statuses).

## How to Compile and Run

1. Ensure you have Java JDK installed (version 11 or higher).
2. Navigate to the project root directory (e.g., `A:/AirTRIBE/Coding/LearnTrack`).
3. Compile the code: Run `javac -d out src/com/airtribe/learntrack/ui/Console.java src/com/airtribe/learntrack/entity/*.java src/com/airtribe/learntrack/util/*.java src/com/airtribe/learntrack/exception/*.java`.
4. Run the application: `java -cp out com.airtribe.learntrack.ui.Console`.
